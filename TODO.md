# Backlog

Состояние на 2026-06-26 (версия 0.5.0-beta). CLI-режим — основной. Архитектура и история этапов:
см. `docs/cli-work-plan.md`.

## Сделано
- CLI-провайдеры (Qwen Code / GigaCode) поверх `service/cli/` (Windows-safe subprocess, таймаут,
  дренаж потоков, кодировка). Стриминг (`stream-json`), кнопка Stop, сессии (`--resume`), выбор модели.
- Редактирование тест-плана агентом через `service/ops/` (fenced `jmeter-ops`): add/remove/set_property/
  replace_subtree + вложенные `children`; превью → подтверждение → применение на EDT; откат
  (кнопка «Откатить» и `@rollback`). Collection-свойства: тело/параметры/заголовки/ассершены.
- Скиллы (`@plan`/`@lint`/`@optimize`) — редактируемые промпт-модули (`~/.gigameter/skills`).
- BlazeMeter/jmeter-plugins элементы (Concurrency/Stepping/Ultimate Thread Group, Throughput Shaping
  Timer, Dummy и т.д.) + профили нагрузки (`utg.schedule`, `tst.schedule`).
- Облачные провайдеры (OpenAI/GigaChat/DeepSeek) скрыты за флагом `gigameter.providers.cloud.enabled`.
- Устойчивость к выводу модели: восстановление обрезанного JSON, толерантный экстрактор, фикс
  обрезки `result` в сессиях. UI/тексты: фиксы mojibake, версия 0.5.0-beta.

## Открыто (приоритет ↓)
- **Приватность**: редакция чувствительных данных (хосты/креды/токены) в сериализованном плане
  перед отправкой облачной CLI-модели.
- **Полноценный undo**: сейчас откат — последний батч ops, в памяти. Нужен JMX-snapshot ring-buffer
  (переживает перезапуск, многошаговый откат). `replace_subtree` undo — best-effort.
- **GigaCode CLI**: возможности заданы по аналогии с qwen, не проверены на живой установке.
- **`@plan import <url>`**: загрузка сценария с веб-страницы → черновик плана (allowlist, лимиты,
  санитизация, anti-injection).
- **UX**: постоянная подсказка по командам (`/help` или кнопка), анимация индикатора «думает…».
- **Атомарность батча**: частичное применение оставляет частичное состояние (откат покрывает
  применённое, но батч не транзакционен) — рассмотреть all-or-nothing.
- **Плагинная валидация плана** после применения батча.
- **Интеграционные тесты** на `OpsApplier`/применение в дерево (сейчас покрыт только слой протокола).
- Мелочи текстов: «Try/Catch/Finally» и тултипы «Navigate Up/Down» по-английски.
