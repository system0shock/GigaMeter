# Ограничения MVP для `@plan`

Этот файл фиксирует известные ограничения текущей реализации `@plan` / `@plan apply`.

## Ограничения по области

1. Поддерживаются только backend-сценарии на основе HTTP.
2. Frontend/browser-сценарии не поддерживаются.
3. Сложная оркестрация (ветвления, многоступенчатая архитектура с несколькими Thread Group) поддерживается ограниченно.

## Ограничения генерации (`@plan`)

1. Качество результата зависит от корректности и полноты JSON-ответа модели.
2. Если модель вернула некорректный/неполный JSON, preview может не построиться.
3. Валидация сейчас облегченная: проверяются только ключевые верхнеуровневые поля.

## Ограничения применения (`@plan apply`)

1. Применение работает только с последним draft-планом в памяти (в рамках текущей сессии).
2. Обязательный порядок: сначала `@plan <сценарий>`, затем `@plan apply`.
3. Повторный запуск `@plan apply` может создать дубликаты (пока нет защиты от повторного применения).
4. Нет единой транзакционной отмены для всей операции применения.
5. Маппинг query/body/headers в текущем MVP базовый.
6. Обработка headers частично структурная и не покрывает все edge-case сценарии.
7. Assertions/extractors создаются с упрощенным набором свойств.

## Эксплуатационные ограничения

1. Плагин не проверяет доступность и корректность внешних endpoint.
2. Нет dry-run diff перед применением (preview пока текстовый).
3. Нет проверки конфликтов с уже существующими похожими элементами в test plan.

## Рекомендуемые следующие шаги

1. Добавить защиту от дубликатов и идемпотентность применения.
2. Добавить структурный diff preview и выборочное применение.
3. Улучшить точный маппинг полей JMeter для headers, query и raw body.
4. Добавить транзакционный undo для всей операции `@plan apply`.
5. Расширить тесты на применение draft-плана к реалистичным деревьям JMeter.

## Краткая инструкция по использованию

1. Откройте чат GigaMeter и выберите модель.
2. Отправьте команду `@plan <ваш backend-сценарий>`.
3. Проверьте текстовый preview в ответе (Thread Group, шаги, assert/extract).
4. Если preview корректный, отправьте `@plan apply`.
5. Проверьте, что элементы появились в дереве Test Plan в JMeter.
6. Если нужно сгенерировать новый вариант, снова отправьте `@plan <новый сценарий>`, затем `@plan apply`.
